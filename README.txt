MHS Dewan Optimis Audio Player

Files:
- index.html: responsive webpage with a native HTML5 audio player
- dewan-optimis.mp3: supplied audio file

To publish:
1. Create a new public GitHub repository.
2. Upload both files to the repository's root folder.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site.
7. Open the published URL on a phone and test Play/Pause.

Embed the published page URL in Google Sites using Insert > Embed > By URL.
Do not embed the raw MP3 URL. Keep the iframe/player area approximately 190-220 px tall initially.
